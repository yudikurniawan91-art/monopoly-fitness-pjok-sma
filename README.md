# Monopoly Fitness PJOK SMA

Game monopoli kebugaran untuk 2-4 pemain, dimainkan bergiliran pada satu perangkat. Tidak memerlukan instalasi atau server aplikasi.

## Mainkan lokal

Buka `index.html` di browser.

## Publish dengan GitHub Pages

Workflow di `.github/workflows/deploy.yml` akan menerbitkan situs setiap kali perubahan didorong ke branch `main`.

1. Buka **Settings > Pages** pada repository.
2. Pada **Build and deployment**, pilih **GitHub Actions** sebagai source.
3. Pastikan workflow **Deploy to GitHub Pages** mendapat izin berjalan, lalu push perubahan ke `main`.
4. URL game akan tampil pada **Settings > Pages** setelah workflow pertama berhasil.
